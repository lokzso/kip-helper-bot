# КИП Помощник PRO + Gemini

Telegram-бот для КИПиА.

## Основные функции
- 4–20 мА, 0–20 мА, 0–10 мА, 0–5 мА
- мА ↔ % ↔ физическое значение
- закон Ома, мощность
- последовательные и параллельные сопротивления
- делитель напряжения
- Pt100 и справка по термопарам
- датчики давления, температуры, уровня, расхода
- диагностика петли
- маркировка резисторов
- обозначения на схемах
- учебный тест
- ИИ-КИПовец через Google Gemini
- определение прибора по фотографии через Gemini

## Render
Обязательно:
- `BOT_TOKEN`
- `PYTHON_VERSION=3.13.5`

Для ИИ:
- `GEMINI_API_KEY`
- `GEMINI_MODEL=gemini-2.5-flash-lite`

Start Command:
`uvicorn app:app --host 0.0.0.0 --port $PORT`

Токены/API-ключи нельзя хранить в публичном GitHub-репозитории — добавляй их только в Environment на Render.
