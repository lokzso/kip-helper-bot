# КИП Помощник MAX

Расширенная версия Telegram-бота для КИПиА.

## Что добавлено
- Рабочий режим
- Универсальный пересчёт 4–20 / 0–20 / 0–10 / 0–5 мА
- Электрокалькуляторы
- Pt100 и термопары
- Пошаговая диагностика
- Режим мультиметра
- Подключение 2/3/4-проводных датчиков
- Фото прибора, шильдика, схемы и резистора
- ИИ с памятью последних сообщений и последнего разобранного фото
- Голосовые вопросы
- База приборов
- «Мои приборы»
- Журнал работ
- Уроки, тесты, XP и уровни
- Поиск документации через Gemini + Google Search grounding, если доступно модели
