# КИП Помощник PRO

Расширенный Telegram-бот для КИПиА.

Внутри:
- 4–20 мА, 0–5 мА, 0–10 В
- мА ↔ % ↔ физическое значение
- закон Ома, мощность
- последовательные/параллельные сопротивления
- делитель напряжения
- Pt100: Ω ↔ °C
- справка по термопарам
- датчики давления, температуры, уровня, расхода
- диагностика петли 4–20 мА
- резисторы: цвета ↔ сопротивление
- обозначения на схемах
- тест из 10 вопросов
- ИИ-КИПовец
- анализ прибора по фото

## Render
Обязательно:
- BOT_TOKEN
- PYTHON_VERSION=3.13.5

Для ИИ и фото:
- OPENAI_API_KEY
- AI_MODEL=gpt-5.6-luna

Start Command:
uvicorn app:app --host 0.0.0.0 --port $PORT
